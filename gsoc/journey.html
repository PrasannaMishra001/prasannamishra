Month by month#

  • 2025
  • 31 Aug 2025

    First pull request

    Human readable contest dates. Opened the day I finished setting the project up. It took six months to merge, mostly because I walked away from it. The same day I left my first comment on a cron script.

  • 9 Sep 2025

    First merge

    A button alignment fix, five days after I opened it.

  • Dec 2025

    Back after three months

    Navbar hover effects. Four rounds of review, and the version that merged threw away my JavaScript for a few lines of CSS.

  • 2026, before the summer
  • Jan 2026

    Seventeen pull requests

    GitHub sign in, the first attempt at system settings, a migration merging eighteen duplicate schools, and a long list of things I was told once and did not need telling twice. Nine merged the same month.

  • 29 Jan 2026

    "Can you split this PR into smaller changes?"

    System settings, 994 lines in one piece, became four pull requests. The last of them merged in July.

  • 9 Feb 2026

    GitHub sign in merges

    Three review rounds on security, accessibility and translation.

  • Feb 2026

    Thirty pull requests, and a lesson about volume

    The busiest month by a distance. Small focused fixes merged within days. A batch of thirteen infrastructure changes opened in two days mostly never got a reply, and neither did three large features nobody had asked for.

  • 5 Mar 2026

    Endpoints that changed data on a GET

    Found by reading how the API routes requests. Merged on 9 May with "Great catch!".

  • Apr 2026

    The Help menu, and a proposal

    One pull request this month, which turned into the summer's navigation work.

  • Google Summer of Code
  • 26 May 2026

    Coding period begins

    The first week went on checking my proposal against main. Other contributors had already merged a good part of it.

  • 4 Jun 2026

    Ankit reviews my test infrastructure

    Thirteen comments. The fake cursor I had built returned the first row forever.

  • 12 Jun 2026

    I withdraw the shadow table swap

    Five reasons it was a bad idea, and a sixth: the problem it solved had already been fixed.

  • 3 Jul 2026

    The first cron pull request merges

    Named constants. Thirty eight days into the coding period.

  • 5 Jul 2026

    Midterm: passed, and "go bigger"

    I sent fourteen project ideas and asked which one omegaUp needed. Juan Pablo picked the cron control plane, then health checks and model training.

  • 13 Jul 2026

    The control plane starts

    A parent issue, then tables, data access, the runner and the admin API opened in one day, each as its own pull request.

  • 14 Jul 2026

    System settings finally closes

    The admin page merges, five and a half months after I opened it, and carries an unmerged pull request into main with it. I start marking stacked pull requests as drafts.

  • 28 Jul 2026

    The tables merge

    Fifteen days after opening. Everything else in the project was waiting on this.

  • 27 Jul to 3 Aug

    Projects two and three

    Model training and problem health checks, opened as stacks behind the control plane.

  • 19 Aug 2026

    The runner merges

    The keystone. The ranking job went through it twenty minutes later, and the other jobs over the next three days. From 22 August every cron job on omegaUp records its runs.

  • 24 Aug 2026

    Coding period ends

    Twenty two pull requests merged inside it, ten of them in the last two weeks.

  • after
  • 29 Aug 2026

    The admin page merges

    Forty six days after I opened it. Three pull requests merged that day.

  • 2 Sep 2026

    The review that changed the number

    Juan Pablo finds that the model score I record as MAP is not MAP. Four findings, four fixes, a test for each.

  • 17 Sep 2026

    The health check job merges

    And the next day, guarded model training.

  • 2 Oct 2026

    Rerun gets split

    One pull request becomes a stack of small ones at the maintainer's request.

  • 7 Oct 2026

    Health checks done

    The findings view merges and closes the issue. A school matching fix from February merges the same day, after seven months.

  • now

    Still going

    Rerun is in review. What comes after it is on After the summer.
